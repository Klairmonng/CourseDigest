# PM - coursedigest-v1
## User stories
1. Log in once and point the tool at a course URL.
2. Read each lesson in 1-2 minutes: plain-English summary, key ideas, a worked example, a diagram.
3. Know which lessons and which moments (timestamps) are worth watching.
4. See each ungraded lab run step by step, with the real model calls and output charts.
5. Revise with flashcards and a glossary.

## Success criteria
- A ~10 h course reads in <= 60 minutes on the site.
- 100% of video/reading lessons digested, or marked failed with a reason.
- Every ungraded lab executed (errors counted) with a walkthrough.
- Re-running any stage without changes costs $0 (cache).

## Out of scope
Portfolio writing, quizzes, graded labs, other platforms.
